# Student Routine Assistant (Telegram Bot)

Асинхронный Telegram-бот на базе **Python 3.14**, **aiogram 3.x** и **Google Gemini Vision API** для автоматизации студенческой рутины колледжа.

## Основной функционал

1. **Распознавание расписания (Vision AI):**
   * Обработка фото расписания с доски или бумаги через `gemini-3.1-flash-lite`.
   * Поддержка фильтрации по конкретным дням недели из подписи к фото.
   * Автоматическая сетка звонков при отсутствии времени на фото.
   * Команды: `/schedule`, `/today`, `/clear_schedule`.

2. **Оперативные изменения расписания (NLP):**
   * Текстовая отмена, замена предметов и смена кабинетов на естественном языке (например: *«В понедельник вместо обществознания будет химия в 304 каб»*, *«Отмени 2 пару»*).

3. **Трекер домашних заданий (ДЗ):**
   * Прием заданий через `#хэштег` (с фото или текстом).
   * Автоматическое сопоставление дедлайна с ближайшей датой предмета в расписании.
   * Интерактивное управление через Inline-кнопки по команде `/hw`.

4. **Умная погода и гардероб:**
   * Интеграция с **OpenWeatherMap API**.
   * Команда `/wear` — срез погоды на текущую минуту с детализацией слоев одежды (верхняя одежда, база, аксессуары/зонт).
   * Команды: `/city <город>`, `/weather`.

5. **Транспортный модуль (Время в пути):**
   * Автоматический расчет времени в пути по адресам дома и колледжа (`/commute`).
   * Учет утреннего часа пик и расчет времени выхода к первой паре в утреннем дайджесте.

6. **Система напоминаний и дайджестов:**
   * Точные напоминания текстом или голосом с привязкой к часовому поясу (`/tz`).
   * Фоновый планировщик **APScheduler**:
     * Проверка напоминаний каждую минуту.
     * Алерт за 15 минут до 1-й пары и за 5 минут до окончания предыдущей пары для всех последующих.
     * Утренний дайджест (07:00) и вечерний дайджест (20:00).

7. **Микро-бюджет и чек-листы:**
   * Быстрый ввод трат без расхода токенов (`250 обед`), отчет по `/expenses`.
   * Интерактивные списки задач и покупок `/todo` с зачеркиванием по кнопке.

8. **Административная панель (`/admin`):**
   * Статистика БД и использование оперативной памяти процессом (RAM).
   * Мягкая пауза (режим техобслуживания) для обычных пользователей.
   * Горячий перезапуск процесса без потери контекста (`os.execv`).
   * Массовая рассылка объявлений (`/broadcast`).

## Стек технологий

* **Язык:** Python 3.14+
* **Telegram Framework:** aiogram 3.x
* **AI:** Google GenAI SDK (`gemini-3.1-flash-lite`)
* **База данных:** SQLite / SQLAlchemy 2.0 (AsyncIO) + aiosqlite
* **Планировщик:** APScheduler 3.x
* **Внешние API:** OpenWeatherMap API
* **Супервизор:** Runit (Void Linux)

## Установка и запуск

```bash
git clone https://github.com/VanyaSloupok404/student_bot.git
cd student_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN, GEMINI_API_KEY, OPENWEATHER_API_KEY и ADMIN_IDS в .env
python3 -m bot.main
